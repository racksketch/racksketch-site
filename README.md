# RackSketch — сайт v0.7.1

Итерация позиционирования на основе действующей v0.6. Логотип, палитра, концепция интерфейса и взаимодействия сохранены.

## Открытие и размещение

- `preview.html` — самостоятельная страница со встроенными стилями, скриптом и SVG; открывается локально без интернета.
- `index.html` + `styles.css` + `script.js` + `assets/` + логотип и favicon — обычная статическая версия.
- Файлы находятся в корне архива. Для обновления статического хостинга используйте `index.html`, `styles.css`, `script.js`, `assets/`, `racksketch-wordmark-05.svg` и `favicon.svg`.
- Никакой сборки, backend, внешних шрифтов, библиотек, аналитики или форм нет. Обновление хостинга автоматически не выполнялось.

## Позиционирование

Первый экран: «Продавайте больше. Согласовывайте быстрее».

Четыре бизнес-выгоды после интерактивного визуала:

1. Сохранять темп разговора с клиентом.
2. Сокращать затраты труда на типовой запрос за счёт меньшего количества передач между отделами.
3. Освобождать проектировщика для сложных проектов.
4. Раньше переходить от согласованной компоновки к комплектации и КП.

Экономический смысл объяснён через процесс. Измеренные результаты, проценты роста конверсии, гарантированная экономия и сроки окупаемости не заявлены.

Отдельно закреплено: RackSketch не заменяет проектировщика, а снимает типовую рутину. Не заявлена замена инженерных расчётов, расчёта несущей способности, проектной документации или CAD для сложных нестандартных проектов.

## Структура

1. Коммерческий смысл на первом экране.
2. Существующая интерактивная концепция интерфейса.
3. Четыре бизнес-выгоды в крупных строках, без сетки карточек.
4. Низкий порог входа и корректное сравнение назначения с AutoCAD.
5. Сценарий продажи: запрос → схема → согласование → предложение.
6. Функции по задачам: собрать план, настроить расстановку, показать результат, поменять вариант.
7. Польза собственнику, руководителям продаж и проектного отдела, менеджеру.
8. Призыв оценить продукт на типовых запросах своей компании.

## Функции

В текстах отражены: помещение, стены, двери/ворота; паллетные/среднегрузовые стеллажи; одиночные/спаренные ряды; точное перемещение; размеры/расстояния; чистый проход; отступы от стен; привязки; план и фронтальный вид; уровни хранения; PDF; сохранение проектов и работа с вариантами.

Это описание возможностей программы по заданию владельца продукта. Интерактивный визуал на сайте остаётся концепцией интерфейса и не изображает полноценную работающую программу. В нём доступны выбор ряда и переключение видов. В отдельной иллюстрации можно сравнить два прохода.

Финальная кнопка показывает рабочий пример на странице. Ссылка на установщик и контакт не добавлены: в исходном сайте их нет, а данные для них не предоставлены.

## Проверки

Chromium: 320, 375, 390, 600, 768, 900, 1024 и 1440 px; отсутствие переполнения и обрезания заголовка. Проверены локальные ссылки, уникальность id, интерактивность, управление клавиатурой, reduced-motion, доступность содержания без JavaScript и автономность preview. SVG логотипа, favicon и скрипт взаимодействий не изменены относительно исходного архива.

Версия v0.7.1 относится только к сайту.

## Точечная правка v0.7.1

Изменены слоган, формулировка задачи в блоке продажи и абзац о работе с вариантами. Упоминание Undo/Redo из текста страницы удалено. Надзаголовок, структура, графика и скрипт сохранены. На широком экране немного уменьшен размер главного заголовка для новой формулировки. Рост продаж обозначен как цель, количественные гарантии отсутствуют.
