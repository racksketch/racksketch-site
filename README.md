# RackSketch — сайт v0.5

Откройте `preview.html`: вся страница содержится в одном файле, включая CSS и SVG.
Для обычного использования откройте `index.html` рядом с остальными файлами.

## Для публикации

Нужны `index.html`, `styles.css`, `racksketch-wordmark-05.svg` и `favicon.svg`.
`preview.html` и этот README для работы сайта не обязательны.
Версия v0.5 относится к сайту. Обозначение v0.4 в блоке статуса относится к программе.

## Что изменено

- Wordmark №5 сохранён байт-в-байт; высота в шапке 44 px (40 px на телефоне), положение оптически скорректировано на 2 px вверх.
- Надзаголовок: обычный регистр, 14 px, вес 650, нормальный трекинг, исходный коралл.
- Снижены размеры H1 и H2, выровнены интервалы и межстрочные расстояния; статус проекта получил менее крупный заголовок.
- В блоке «Для кого» текст роли и её описание стоят друг под другом, чтобы не дробить длинные строки.
- Убраны наклон иллюстрации, подъём кнопок при наведении и тяжёлые тени. Шесть карточек и четыре шага сохранены.
- Значки карточек приведены к единому линейному SVG-стилю.
- Схематичная иллюстрация получила относительные размеры рядов и обычную подпись в figure. Число секций в свойствах согласовано с верхним рядом.
- CSS сведён к одной палитре и одному набору правил, без накопленных экспериментальных переопределений.

## Сохранено

Исходные разделы, порядок блоков, позиционирование и тексты, выбранная палитра, SVG логотипа и favicon. Форм, JavaScript, внешних шрифтов, аналитики и сетевых зависимостей нет. Иллюстрация остаётся схематичной; нового реального снимка программы здесь нет.

## Проверка

Проверены локальные ссылки, SVG, идентичность логотипа и favicon, CSS и архив. Логотип отрисован для проверки оптического центра. Правила адаптации просмотрены для узких и широких экранов.
Полный браузерный рендер выполнить не удалось: загрузчик Chromium в этой среде получил HTML вместо архива браузера. Вёрстка пока не прошла визуальный QA в браузере.
